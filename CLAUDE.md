# Working in BLD8 UI

Read and follow [AGENTS.md](AGENTS.md), then [README.md](README.md),
[the current handoff](docs/handoff.md) and [the ordered next work](docs/next-work.md).
AGENTS.md is the shared contributor guide for source authorities, regeneration,
validation, immutable releases and the owner's account/commit-time restrictions.

For using the library from another project, read
[the developer and agent documentation](docs/agents.md) and
[local MCP setup](docs/mcp.md). Those discovery tools are read-only reference
material; they do not authorise installation, source overwrite or publication.
